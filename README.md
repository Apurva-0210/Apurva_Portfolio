## Local Development

### Prerequisites

- Node.js
- npm or Yarn
- Python 3.x
- Git

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The development server will start locally.

### Backend

```bash
cd backend
pip install -r requirements.txt
python server.py
```

Environment-specific configuration should be placed in `.env`. Use the provided `.env.example` files as templates.

## Security

Sensitive configuration is intentionally excluded from version control.

The repository ignores:

```text
.env
.env.*
credentials.json
token.json
*.pem
node_modules/
dist/
```

Only example configuration files such as `.env.example` should be committed.
