# Application Audit Report

**Project:** Apurva Kumar — Engineering & Systems Portfolio  
**Audit Date:** November 23, 2026  
**Audited By:** Integrated Senior Software Engineering & QA Organisation  
**Environment:** macOS (darwin-arm64), Node.js v26.8.2, Python 3.12, Chromium  

---

## 1. Executive Summary

This comprehensive audit evaluated the Apurva Kumar engineering portfolio repository across design, frontend architecture, backend infrastructure, interactive behavior, responsive fidelity, accessibility (WCAG 2.2 AA), security, and quality assurance. 

The portfolio showcases deep technical systems engineering (Heavy Commercial Vehicle ADAS, gem5 computer architecture, Massive MIMO neural transformers, and nanocomposite gas sensors). While the visual aesthetics and core content are strong, several functional, architectural, responsive, and accessibility defects were identified that prevent it from functioning as a tier-1 commercial-grade software product.

## 3. Discovered Defects & Technical Debt

### 3.1 Functional & Prop Disconnects (High Severity)
1. **Hardcoded Template Strings Overriding Props:**
   In `frontend/src/components/ui/crimson-reach-template.tsx`, key props passed from `Home.tsx` (`worksTitle="Featured Engineering Work"`, `ctaTitle="Let’s engineer something reliable"`, `servicesTitle="Engineering Capabilities"`, `journeyTitle="Three Layers. One Architecture."`) are ignored in the JSX in favor of hardcoded strings. `quotesTitle` is completely unrendered.
2. **Disconnected Live GitHub Integration:**
   `frontend/src/lib/github.ts` defines `fetchGithubPortfolio()` and TypeScript interfaces, and `backend/routers/github.py` implements the proxy endpoint, but neither is surfaced in the UI. Visitors cannot view live GitHub metrics (stars, forks, commit activity).
3. **No Project Deep-Dive / Modal Inspection:**
   All 12 project cards link directly out to external GitHub repos, losing visitor retention. Users cannot inspect full architecture diagrams, technology stack tables, or implementation notes in-page.

### 3.2 Responsive & UX Deficiencies (High Severity)
1. **Missing Mobile Navigation Menu:**
   On viewports $\le 860\text{px}$, `.cr-links` is hidden via CSS `display: none` without providing an accessible mobile navigation drawer, hamburger button, or jump sheet. Mobile users cannot navigate to Focus, Capabilities, Projects, Experience, or Contact.
2. **Carousel Blank Flash:**
   Off-screen carousel cards with `data-d="far"` have `loading="lazy"`. Rapidly cycling through projects triggers lazy downloads during animation transitions, causing noticeable blank flashes.
3. **No Project Categorization / Filtering:**
   All 12 projects are in a linear carousel without filtering (e.g. *Autonomous & ADAS*, *Computer Architecture*, *Edge AI & Wireless*, *Hardware & Sensors*).

### 3.3 Accessibility & Usability (WCAG 2.2 AA) (Medium Severity)
1. **Focus State Indicators:** Carousel navigation arrows and jump links lack high-visibility `:focus-visible` outline rings for keyboard-only navigation.
2. **Touch Target Size:** Carousel indicator dots and mobile buttons occasionally fall below the minimum $44 \times 44\text{px}$ touch target requirement.
3. **ARIA Semantics:** Missing `aria-live="polite"` regions on carousel slide changes, leaving screen reader users unaware of active card transitions.

### 3.4 Code Smells & Hygiene (Low Severity)
1. **React Fast Refresh Warnings:** 20+ warnings generated by `oxlint` due to non-component exports (`badgeVariants`, `buttonVariants`, utility functions) alongside React components.
2. **Unused Imports:** `profile` imported in `Home.tsx`; `withBase` imported in `crimson-reach-template.tsx`.
3. **External CDN Reliability:** Atmospheric background images (`statue.webp`, `hero.webp`, `dunes.webp`) depend on an external third-party CDN domain (`kedhar-components.pages.dev`).

---

## 4. Remediation Plan

1. **Design System & Tokens:** Establish formal tokens for colors, typography scales, glass surfaces, border treatments, and elevation in `DESIGN_SYSTEM.md`.
2. **Component Architecture:** Refactor `crimson-reach-template.tsx` to honor all props, add accessible mobile navigation drawer, integrate interactive project deep-dive modals, and add category filters.
3. **Live Telemetry & GitHub Integration:** Surface live GitHub stats with graceful offline fallback.
4. **Performance & Motion:** Optimize image loading (`loading="eager"` for carousel items, local fallback assets), respect `prefers-reduced-motion`.
5. **Quality Assurance:** Execute Playwright E2E suites across 6 viewports (360px to 1920px), run Vitest unit tests, and perform accessibility audits.
